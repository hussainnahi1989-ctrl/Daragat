الطريقة الأولى (الأسهل فوراً): PWA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. افتح الرابط من كروم على الهاتف:
   https://hussainnahi1989-ctrl.github.io/Daragat/
2. اضغط زر القائمة (⋮) الثلاث نقاط أعلى الكروم
3. اختر "تثبيت التطبيق" أو "Add to Home screen"
4. اضغط "تثبيت"
→ سيظهر أيقونة التطبيق على الشاشة الرئيسية كأي تطبيق أندرويد
→ يعمل بشاشة كاملة بدون شريط العنوان
→ جميع الميزات تعمل بما فيها الطباعة والتصدير والاستيراد والواتساب

الطريقة الثانية: ملف APK جاهز
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
بعد رفع ملفات المشروع إلى GitHub، سيتم بناء ملف APK تلقائياً.
لتحميله:
1. افتح صفحة المشروع على GitHub
2. اضغط على تبويب "Actions" بالأعلى
3. اختر أحدث عمل "Build Android APK" (العلامة الخضراء ✅)
4. في نهاية الصفحة ستجد ملف "daragat-apk" قم بتحميله
5. انقل الملف للهاتف وافتحه لتبدأ التثبيت
   (قد تحتاج تفعيل "تثبيت من مصادر غير معروفة" في الإعدادات لأول مرة)

📝 ملاحظة: نسخة APK من ملفات GitHub Actions تتطلب أن ترفع ملف
.github/workflows/build-apk.yml مع باقي الملفات إلى GitHub.

📄 ميزة جديدة: يظهر زر PDF بجانب كل زر طباعة لتنزيل ملف PDF مباشرة إلى ملفات الهاتف، مع الحفاظ على نفس مقاس وتخطيط الطباعة.

🆕 إصدار 1.10.0: PDF حقيقي بنصوص قابلة للتحديد والبحث والتعديل في برامج تحرير PDF، مع إصلاح الطباعة على Android وiPhone وHuawei وWindows.
