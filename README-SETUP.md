# الاداره المدرسيه - نظام التفعيل 🎓

## ملفات المشروع
- `index.html`  → التطبيق الرئيسي (مع نظام التفعيل)
- `admin.html`  → لوحة تحكم الأدمن (الموافقات، المفاتيح، الحسابات)
- `firebase-rules.json` → قواعد أمان قاعدة البيانات

---

## خطوات الإعداد (مرة واحدة)

### 1. إنشاء مشروع Firebase
1. اذهب إلى https://console.firebase.google.com/
2. اضغط **Add project** → اسم المشروع (مثلاً `daragat-app`) → عطّل Analytics → Create
3. بعد إنشاء المشروع:
   - من القائمة اليسرى → **Build** → **Realtime Database**
   - اضغط **Create Database** → اختر أي منطقة (مثلاً europe-west1) → اختر **Start in test mode** (سنغير القواعد لاحقاً)
4. من الصفحة الرئيسية للمشروع → اضغط **Add app** → اختر **Web app** (`</>`)
   - سجّل اسم التطبيق (مثلاً `daragat-web`)
   - لا تحتاج Hosting حالياً
   - اضغط **Register app**
   - ستظهر لك كود يحتوي على `firebaseConfig` — انسخ الكائن `{...}` كاملاً

### 2. ضبط الإعدادات في لوحة الأدمن
1. ارفع `index.html` و `admin.html` إلى استضافتك (GitHub Pages أو أي استضافة)
2. افتح `admin.html` في المتصفح
3. اضغط **الإعدادات** من أسفل شاشة الدخول
4. الصق كائن `firebaseConfig` في مربع النص
5. غيّر **كلمة سر الأدمن** (كلمة السر الافتراضية `hsm@2026`)
6. **السر المشترك** ابقه كما هو (`HSM-DARAGAT-2026-V1`) أو غيّره — ولكن يجب أن يكون نفسه في `index.html`
7. اضغط **حفظ**

### 3. نسخ إعدادات Firebase إلى `index.html`
- افتح `index.html` بمحرر نص، ابحث عن `REPLACE_WITH_API_KEY`
- استبدل القيم السبع بالقيم من مشروع Firebase (نفس القيم التي وضعتها في لوحة الأدمن)

### 4. (اختياري) قواعد الأمان
لمنع أي شخص من مسح البيانات، استبدل قواعد Realtime Database بالمحتوى في ملف `firebase-rules.json`
من Firebase Console → Realtime Database → Rules → الصق القواعد → Publish.

### 5. رفع GitHub Pages
لأن لديك مستودع `https://github.com/hussainnahi1989-ctrl/Daragat`:
1. ادفع الملفات `index.html` و `admin.html` إلى الفرع `main`
2. من إعدادات المستودع → Pages → اختر `main branch` → `/ (root)` → Save
3. سيصبح التطبيق متاحاً على: `https://hussainnahi1989-ctrl.github.io/Daragat/index.html`
   ولوحة الأدمن على: `https://hussainnahi1989-ctrl.github.io/Daragat/admin.html`

## كيفية الاستخدام

### من جهة المستخدم (مدير المدرسة)
1. أول فتح للتطبيق → يبدأ **النسخة التجريبية 3 أيام**
2. عند انتهاء التجربة:
   - ينسخ **معرّف الجهاز**
   - إما **(أ)** يملأ بطاقة التفعيل ويرسلها → تظهر في لوحتك → توافق فتتفعل تلقائياً
   - أو **(ب)** يرسل لك معرّف الجهاز عبر واتساب، وتولّد له مفتاحاً من تبويب "توليد مفتاح" في لوحة الأدمن، ويعطيه إياه فيدخله فيعمل التطبيق بدون إنترنت
3. بعد التفعيل يعمل التطبيق **بدون إنترنت** بالكامل (البيانات محفوظة محلياً في جهازه كما سبق)

### من جهة الأدمن
افتح `admin.html` → سجّل دخول بكلمة السر، ثم تظهر التبويبات:
- **الكل**: جميع الطلبات والحسابات
- **طلبات اليوم**: الطلبات المستلمة اليوم فقط
- **المفعّلة**: الحسابات الموافق عليها
- **غير المفعّلة**: الطلبات التي تنتظر الموافقة
- **الحسابات**: كل المشتركين المفعّلين مع تاريخ التفعيل والانتهاء وحقل مبلغ الشراء (قابل للتعديل)
- **🔑 توليد مفتاح**: إنشاء مفاتيح أوفلاين مربوطة بجهاز+خطة
- **⚙️ الإعدادات**: تغيير كلمة السر وإعدادات Firebase

## 📤 كيف ترفع تحديثاً جديداً للزبائن (بسيط جداً)

1. عدّل على `index.html` محلياً
2. **ارفع رقم النسخة** داخل `index.html`: ابحث عن السطر
   ```js
   const APP_VERSION = "1.0.0";
   ```
   وغيّره إلى رقم أعلى، مثلاً `"1.0.1"` أو `"1.1.0"`
3. **افتح ملف `version.json`** وغيّر `"version": "1.0.0"` إلى **نفس الرقم الجديد**
4. ادفع كلا الملفين (`index.html` و `version.json`) إلى GitHub
5. خلال **30 ثانية** سيظهر عند كل زبون شريط برتقالي في الأعلى 🔄:
   - زر **"تحديث الآن"** → يعيد تحميل النسخة الجديدة فوراً
   - زر **"لاحقاً"** → يُخفي الشريط لمدة 4 ساعات ثم يظهر مجدداً
6. **إذا لم يضغط الزبون شيئاً** يبقى الشريط ظاهراً حتى يحدّث، لكن التطبيق يستمر يعمل بشكل طبيعي على نسخته القديمة — لا يُجبَر أحد على التحديث.

ملاحظة: بمجرد ضغط الزبون "تحديث الآن" يتم إجبار المتصفح على تحميل الملفات الجديدة من السيرفر (يكسر الكاش تلقائياً) — لا حاجة لـ Ctrl+F5.

## ملاحظات أمنية
- كلمة سر الأدمن محفوظة كـ hash في متصفحك فقط.
- مفاتيح الأوفلاين مربوطة بمعرّف الجهاز ونوع الاشتراك — لا تعمل على جهاز آخر.
- إذا أردت حماية أقوى (منع العملاء من الموافقة على أنفسهم)، يمكنك لاحقاً تشغيل Firebase Authentication وجعل الكتابة تتطلب تسجيل دخول؛ لكن للاستخدام الحالي (عدد محدود من العملاء والتواصل عبر واتساب) النظام كافٍ.

## تنزيل الطباعة كملف PDF مباشر

تظهر أيقونة **🖨️ طباعة وتصدير** في أماكن الطباعة والتصدير. عند الضغط عليها تظهر خيارات **طباعة** و**تصدير PDF**؛ ويُنشأ PDF محلياً من نفس صفحة الطباعة وبنفس اتجاهها وحجمها، دون إرسال البيانات إلى خادم. لا يتم إرسال بيانات الطلاب أو الدرجات إلى أي خادم أثناء إنشاء الملف.

- يعمل مع الطباعة العمودية والأفقية والبطاقات والكشوف والسجلات.
- لا يغيّر تخطيط الطباعة الأصلي ولا أحجام الصفحات.
- إذا كان الكشف كبيراً، انتظر حتى تظهر رسالة اكتمال التنزيل قبل مغادرة الصفحة.

### ملاحظات إصدار 1.10.0 — PDF حقيقي والطباعة متعددة الأنظمة

- مولّد PDF الجديد ينشئ نصوصاً حقيقية داخل الملف باستخدام خط عربي مضمّن، وليست صورة للصفحة؛ لذلك يمكن تحديد النص والبحث فيه وتعديله ببرامج تحرير PDF التي تدعم تحرير النصوص.
- يحافظ المولّد على مقاس الصفحة واتجاهها وتخطيطها الأصلي، مع بقاء مسار الطباعة التقليدي منفصلاً عن التصدير داخل القائمة الموحدة.
- تمت معالجة الطباعة داخل إطار مستقل لتعمل بصورة أفضل في Chrome وAndroid وiPhone وHuawei وWindows.

### إصدار 1.10.1 — اختيار مكان واسم ملف PDF

قبل حفظ PDF تظهر نافذة تتيح تغيير اسم الملف. في Chrome وEdge والأنظمة التي تدعم نافذة الحفظ يمكن اختيار المجلد والاسم مباشرة. في iPhone وAndroid وHuawei يظهر خيار المشاركة، ومنه يمكن اختيار تطبيق «الملفات» والمجلد المطلوب. ويوجد أيضاً خيار تنزيل بالاسم المحدد كحل متوافق مع بقية المتصفحات.

### إصدار 1.10.2 — إصلاح العربية والحفظ المباشر

تم إصلاح اتجاه النص العربي داخل PDF. وعند توفر نافذة الحفظ في النظام، يفتح زر PDF نافذة اختيار المجلد والاسم قبل إنشاء الملف، ثم يُكتب الملف مباشرة في المكان الذي اختاره المستخدم. وفي iPhone وAndroid وHuawei يمكن استخدام خيار المشاركة لحفظه من تطبيق الملفات.


### إصدار 1.10.3 — إصلاح الطباعة وقائمة طباعة وتصدير

- تم إصلاح تنفيذ الطباعة عبر إطار طباعة مستقل لا يتم إخفاؤه بطريقة تمنع Android أو WebView من فتح نافذة الطباعة.
- تم دمج أزرار الطباعة وتصدير PDF في أيقونة واحدة باسم **طباعة وتصدير**. وعند وجود عمودي/أفقي أو طباعة طالب/الجميع، تظهر الاختيارات داخل القائمة الفرعية مع الحفاظ على كل مسار كما كان.
- لم تتغير قوالب الطباعة أو أحجام A4 والبطاقات أو الهوامش أو اتجاهات الصفحات.
- بقي PDF ملفاً حقيقياً بنصوص متجهية وخط عربي مضمّن، مع اختيار الحفظ المباشر أو المشاركة/حفظ في الملفات أو التنزيل الاحتياطي.
